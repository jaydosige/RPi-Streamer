AirPlay

An iPhone, iPad or Mac mirrors onto this node from the AirPlay picker. Receiving takes the screen, so it is a source like any other — starting it stops whatever is playing, and the screen stays black until somebody actually connects.

    Connect by address

    Bypasses discovery entirely. If the Pi can route to the sender, this connects regardless of what mDNS is doing — which makes it the thing to try when a source refuses to appear, and the reliable option across VLANs or on a multi-homed node.

    NDI networking

    For a node with two networks — Wi-Fi for management, Ethernet for media. These go into the NDI SDK's own config file, not the pipeline, and changing them restarts discovery.
    Get the interface restriction wrong — an address that does not exist on this Pi — and NDI may stop working entirely. Leave it blank unless you are certain.

      Guest sharing
      
      
      
        Opens a one-page upload site for the room. Anyone who scans the code can
        send a photo or a video from their phone — nothing else on the node
        is reachable from it. It closes itself when the time runs out.
      
      
      
      
      
        
    
        

    
        
      
        Playlists
        
      
        
        A playlist carries its own loop, shuffle and still-image dwell settings.
        Videos always play to their natural end.
      
        
      
          
      
          
        
      
          
    
          

    
          
      
          Edit playlist
          
      
      
      
          
        
        
        
        
      
          
      
          
        Leave the duration blank for a video to play it to its end. An NDI source
        has no natural end, so it needs one. Mixing NDI into a playlist means each
        item is a separate process, so expect a brief black frame between items.

            This node
            
      
              
      
              
        
        
      
              
      
              
        Applies to the whole group, over whatever is playing, and to nodes that
        are not playing anything. It survives a reboot on purpose: if you flagged
        a node because you were looking for it, finding it should not depend on
        the node staying up.
      
              
    
              

    
              
      
              Group
              
      
              
        Nodes announce themselves every two seconds and disappear from this list
        twelve seconds after they stop. Only nodes in the same group, signed with
        the same key, are ever listed.
      
              
      
              
      
                
      
                
        
        
        
        
      
                
    
                

    
                
      
                Synchronised playback
                
      
                
        Send a playlist to every node, then play it in step. Each item is loaded
        and held paused on all nodes, released on an agreed instant, and then
        kept in line while it plays. Only files are synchronised — an NDI
        source is already live and has its own timing.
      
                
      
      
                
        
        
        
        
      
                
      
                
      
                  
    
                  

    
                  
      
                  Group settings
                  
      
                  
        
        
      
                  
      
      
      
      
                  
        
        
      
                  
      
                  
        With this off you still get a synchronised start for every item, just no
        correction afterwards — which is enough for short clips and avoids
        any chance of a visible correction mid-item.

                  What this box can do
                  
      
                  
      
                  
    
                  
    
                  
      
                  Dropped frames
                  
      
                  
        
        
      
                  
      
                  
        On by default. The sink discards frames that arrive late so the picture
        stays in sync with the clock. If the Pi is only slightly too slow, this
        is usually the thing turning "a bit behind" into visible dropped frames
        — turning it off often fixes the symptom outright.
      
                  
      
                  
        
        
      
                  
      
                  
        Off means every frame is shown the moment it arrives. Motion can judder
        very slightly, but nothing is thrown away. For signage and IMAG that is
        usually the better trade.
      
                  
      
    
                  
    
                  
      
                  CPU cost
                  
      
      
      
      
      
                  
        
        
      
                  
      
                  
        Cheapest possible, because videoscale becomes a passthrough. It only
        works if your display advertises a mode matching the source exactly;
        if it does not, the pipeline falls back to the pinned mode.
      
                  
    
                  
    
                  
      
                  Buffering
                  
      
      
      
      
      
    
                  
    
                  
      
                  Standby screen
                  
      
                  
        What the display shows when nothing is playing. The standby screen is a
        live output, not the absence of one — that is what keeps the Linux
        console off the screen.
